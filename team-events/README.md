# Monthly Team Event — Fun Games Playbook

Ready-to-run games for monthly org fun sessions (Bingo-style mixers, trivia, scavenger hunts, and more).

## Files

| File | Purpose |
|------|---------|
| `Monthly_Team_Event_Games_Playbook.pptx` | Facilitator PowerPoint (rules, cards, questions, answer keys) |
| `Team_Event_Games_Playbook.html` | Same content in browser form (Print → Save as PDF) |
| `create_playbook_ppt.py` | Script to regenerate the deck |

**Direct PPTX download (from this branch):**  
https://github.com/apoorvgl152/course/raw/cursor/team-event-games-ppt-eb4d/team-events/Monthly_Team_Event_Games_Playbook.pptx

## Games included

1. **Human Bingo** — icebreaker mixer + printable-style card
2. **Two Truths and a Lie** — storytelling + voting
3. **Team Trivia Sprint** — 3 rounds + full answer key
4. **Photo Scavenger Hunt** — creative photo challenges + scoring
5. **Emoji Charades** — act / emoji-guess prompts
6. **Minute Challenges** — 60-second mini-games
7. **Would You Rather** — quick debate prompts
8. **Office Olympics** — silly desk sports

## Suggested 60-minute flow

1. Welcome (5 min)
2. Human Bingo (15 min)
3. Team Trivia Sprint (20 min)
4. Charades or Photo Hunt (15 min)
5. Awards (5 min)

## Regenerate the PPT

```bash
python3 team-events/create_playbook_ppt.py
```

Requires `python-pptx`.
